# Diplom_3
Дипломный проект. Задание 3: тестирование UI для приложения Stellar Burgers с помощью паттерна Page Object Model. Структура проекта:

1. папка locators содержит локаторы для элементов, требующихся для проведения тестирования. Они разделены следующим образом:
- страница входа,
- главная страница,
- лента заказов,
- личный кабинет пользователя,
- восстановление пароля.
2. папка pages содержит методы для написания тестов. Методы разделены по функциональности:
- базовые методы,
- методы проверки функционала входа в аккаунт,
- методы проверки основного функционала приложения,
- методы проверки функционала раздела Лента заказов,
- методы проверки работы личного кабинета,
- методы проверки восстановления пароля.
3. папка tests содержит тесты, проверяющие вышеперечисленные аспекты функционала приложения:
- проверка основного функционала приложения,
- проверка функционала раздела Лента заказов,
- проверка работы личного кабинета,
- проверка восстановления пароля.
4. файл conftest содержит:
- метод инициализации драйвера для двух браузеров: Chrome и Firefox
- фикстуру создания и удаления пользователя.
- фикстуру создания заказа на основе созданного пользоваля,
5. файл data содержит адреса отдельных страниц проверяемого приложения, а также данные имени и мэйла для входа в аккаунт.
6. файл requirements содержит список необходимых библиотек для работы с данным проектом.
7. файл README содержит описание проекта.
8. папка allure_results содержит отчёт о тестировании.
